# 后端 Engineering Profile

它是统一 `engineering` Skill 使用的 Design 与验证特化，不是独立工作流或命令。

RAM 必须发生在实现前：

- **Read** 位于 Explore：读取权威策略、最近路径上下文、相关代码、测试、契约和历史。
- **Analyze** 位于 Explore/Spec：识别不变量、所有者、信任边界、调用方、兼容性、数据迁移、失败模式和运营风险。
- **Model** 位于 Design：确定领域边界、接口、持久化规则、权限、幂等、事务/并发、观测和实现顺序。

Apply 只消费已审批模型。按真实风险运行聚焦测试、编译/构建、架构 Fitness、契约测试、迁移演练，以及适用的安全或并发证据。命令来自 `agent-policy.yaml`。
