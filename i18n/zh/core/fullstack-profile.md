# 全栈 Engineering Profile

全栈工作只使用一个变更、一个行为契约、一次审批和一套最终证据，不再使用旧双命令工作流。

Design 必须定义 API 边界两侧的版本、空值、校验、错误、权限、幂等、重试/超时、时区/精度、观测、生成类型和所有权。后端 Model 与前端 Decompose 都是同一 `design.md` 的章节。

多 Agent 只是可选执行机制，不是生命周期。Design 将后端、前端、生成契约和集成工作写入共享 `task-plan.json` DAG。Worker 只能在审批后启动，必须使用隔离或不重叠范围，并把证据交回唯一协调者。串行执行使用完全相同的任务图、契约和门禁。Review 校验字段、枚举、错误、权限、路由和消费者对齐，并执行两侧项目门禁。
