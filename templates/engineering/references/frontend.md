# Frontend Profile

Read the applicable project instructions first, then `docs/methodology/core/frontend-profile.md`.

During Design, follow `docs/methodology/core/design-review.md`. Use Decompose to define route/component ownership, state/event/data flow, API/type contracts, design-system reuse, responsive behavior, accessibility, and loading/empty/error states. The topology and runtime-flow views must make state ownership and user-visible failure paths explicit. During Apply, perform only scoped drift checks before implementation. Run the frontend commands declared in `docs/methodology/agent-policy.yaml`; framework and design-system conventions come from project/path instructions.

Required review evidence includes applicable typecheck, focused tests, build, accessibility checks, and API contract alignment.
