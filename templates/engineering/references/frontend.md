# Frontend Profile

Read the applicable project instructions first, then `docs/methodology/core/frontend-profile.md`.

During Design, use Decompose to define component ownership, state/data flow, API/type contracts, accessibility behavior, and loading/empty/error states. During Apply, perform only scoped drift checks before implementation. Run the frontend commands declared in `docs/methodology/agent-policy.yaml`; framework and design-system conventions come from project/path instructions.

Required review evidence includes applicable typecheck, focused tests, build, accessibility checks, and API contract alignment.
