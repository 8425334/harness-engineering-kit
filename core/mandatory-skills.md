# Mandatory Skills

The `engineering` Skill is the governance shell for non-trivial changes. Native
OpenSpec Skills own lifecycle actions:

| Capability | Owner |
|---|---|
| Explore, Propose, Apply, Sync, Archive, Update | OpenSpec native Skills |
| Validate, status, instructions, schema inspection | OpenSpec CLI |
| Context, approval, execution/review evidence, Fitness, production | Engineering |

If OpenSpec or a required native Skill is unavailable, stop lifecycle work and
report the missing dependency. Do not recreate the OpenSpec workflow in
Engineering.
