# coil-backend-api Fitness Adaptation

The project declares real fast, normal, and deep gate commands in `agent-policy.yaml` and keeps rule-specific configuration under `docs/fitness/`.

Typical checks cover module dependency direction, domain framework isolation, permission annotations and SQL seeds, Mapper/XML parity, migration placement, changed-code tests, frontend typecheck/build, debug-output cleanup, security configuration, and SDD artifact quality.

Fitness signals are risk proxies, not proof. `review-evidence.json` records exact commands, exit codes, uncovered cases, and approved exceptions.
