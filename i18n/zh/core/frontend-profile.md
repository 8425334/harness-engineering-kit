# 前端 Engineering Profile

它是统一 `engineering` Skill 使用的 Design 与验证特化，不是独立工作流或命令。

RAD 必须发生在实现前：

- **Read** 位于 Explore：读取产品行为、设计系统、路由、组件、API 类型、状态所有权、测试和无障碍约束。
- **Analyze** 位于 Explore/Spec：识别用户状态、权限边界、响应式行为、兼容性、加载/空/错误状态和契约风险。
- **Decompose** 位于 Design：确定组件职责、数据/状态流、类型化 API 边界、校验、交互状态、无障碍和实现顺序。

Apply 只消费已审批分解。按 `agent-policy.yaml` 的命令验证类型安全、聚焦行为测试、无障碍、构建、三态表现和 API 对齐。
